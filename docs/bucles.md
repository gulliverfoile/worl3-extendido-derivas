# Bucles de retroalimentación

El modelo no es una lista de variables. Es un sistema de bucles
acoplados. Estos son los principales.

## Gaia

- **Deshielo → albedo**: menos hielo → menos reflexión → más calor
  → más deshielo. Bucle positivo.
- **Permafrost → metano**: más calor → más permafrost liberado →
  más metano → más calor. Bucle positivo con umbral.
- **CO₂ → absorción**: más CO₂ → menos absorción oceánica → más CO₂.
  Bucle positivo con saturación.

## Economía

- **Capital → recursos**: más capital → más extracción → menos
  recursos → más coste → menos capital. Bucle negativo.
- **Capital → emisiones**: más producción → más emisiones → más
  daño ecológico → menos población → menos producción. Bucle
  negativo con retardo.

## Captura

- **Control → peaje**: más control → más peaje → menos reinversión
  → menos capital → más narrativa → más control. Bucle positivo.
- **Presión ecológica → narrativa**: más daño → más presión → más
  narrativa → más coste de perpetuación → captura agotada. Bucle
  negativo con umbral.

## Subjetividad

- **Carga → burnout**: más carga laboral → más burnout → menos
  productividad → menos producción → menos sentido → más burnout.
  Bucle positivo vicioso.
- **Captura → atención**: más captura de información → menos
  atención → menos confianza → menos productividad. Bucle negativo.

## Acoplamientos entre capas

- **Captura → Economía**: el filtro de información distorsiona la
  productividad percibida. La economía decide con datos falsos.
- **Economía → Gaia**: la extracción emite. Gaia se calienta. El
  EROI ecológico cae.
- **Gaia → Subjetividad**: el daño ecológico sube el burnout. Menos
  productividad. Menos capacidad de mitigación.
- **Captura → Subjetividad**: más peaje → menos producción libre →
  menos sentido → más burnout.
- **Subjetividad → Economía**: más burnout → menos productividad
  real → menos producción → menos reinversión.

## Lo que no está modelado

- Retardos explícitos (los efectos son inmediatos).
- Deslocalización geográfica (un solo mundo).
- Tipos de fuerza laboral (una sola productividad).
- Tipping points múltiples (solo unos pocos umbrales).
- Tecnología endógena (no hay cambio técnico dentro del modelo).
